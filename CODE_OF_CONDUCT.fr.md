# Code de conduite

## Notre engagement

En tant que participants, nous nous engageons à faire de la participation à ce projet une expérience sans harcèlement pour tout le monde, quels que soient l'âge, la corpulence, le handicap visible ou invisible, l'origine ethnique, les caractéristiques sexuelles, l'identité et l'expression de genre, le niveau d'expérience, l'éducation, le statut socio-économique, la nationalité, l'apparence physique, la race, la religion, ou l'identité et l'orientation sexuelles.

## Nos standards

Exemples de comportements qui contribuent à un environnement positif :

- Utiliser un langage accueillant et inclusif
- Respecter les points de vue et expériences différents
- Accepter avec grâce la critique constructive
- Se concentrer sur ce qui est le mieux pour le projet

Exemples de comportements inacceptables :

- L'usage d'un langage ou d'images à caractère sexuel, et toute attention sexuelle non désirée
- Le trolling, les commentaires insultants ou dégradants, les attaques personnelles ou politiques
- Le harcèlement public ou privé
- La publication d'informations privées d'autrui sans permission explicite

## Périmètre

Ce Code de conduite s'applique dans tous les espaces du projet (issues, pull requests, discussions), ainsi que lorsqu'une personne représente le projet dans des espaces publics.

## Signalement

Les cas de comportement inacceptable peuvent être signalés en ouvrant une [alerte de sécurité privée GitHub](https://github.com/MarvinLeRouge/JobFlow/security/advisories/new) ou en contactant directement le mainteneur. Toutes les plaintes seront examinées et traitées rapidement et équitablement.

## Barème des sanctions

Le mainteneur suivra ce barème pour déterminer les conséquences de toute action jugée contraire à ce Code de conduite :

1. **Correction** - Un avertissement privé écrit, précisant la nature de la violation.
2. **Avertissement** - Un avertissement avec des conséquences en cas de récidive. Aucune interaction avec les personnes concernées pendant une période donnée.
3. **Restriction temporaire** - Une interdiction temporaire de toute interaction ou communication publique avec le projet, pour une période donnée.
4. **Exclusion permanente** - Une interdiction permanente de toute interaction publique avec le projet.
